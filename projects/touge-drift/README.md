# Touge Drift

[← Back to portfolio](../../README.md)

## Overview

Touge Drift is a stylized touge racing project built around responsive sim-cade vehicle handling, Japanese mountain-road driving, procedural route generation, and a strong low-poly / flat-shaded visual direction.

My work on the project covers the full production stack: gameplay programming, vehicle systems, procedural tools, cameras, UI, technical art, and 3D asset production.

![Cover](assets/images/cover.png)

## My Role

- Gameplay programming
- Vehicle physics and handling
- Procedural track / route systems
- Camera architecture
- UI / UX implementation
- Shader and technical-art systems
- 3D environment and vehicle production
- Game design and prototyping

## Key Systems

### Vehicle Physics

Custom sim-cade vehicle systems including suspension behavior, longitudinal and lateral tire forces, drivetrain logic, assists, telemetry, weight transfer, and handling tuning.

### Procedural Route Generation

Runtime road generation built around deterministic seeds, authored road segments, curves and hairpins, streaming, progress tracking, and reusable environment systems.

### Camera & Presentation

Gameplay camera architecture designed for chase-camera behavior, reusable shake events, pause/result camera states, and presentation-driven transitions.

### UI / UX

Gameplay HUD, pause flow, controller navigation, notifications, settings, and menu systems designed for gamepad-first interaction.
